# QA Portfolio – Yehuda Gutmann

This repository serves as a central hub for my QA work, showcasing hands-on experience in manual testing, test design, automation, and system-level validation.

The focus of this portfolio is not only on tools, but on **testing mindset, real-world scenarios, and structured thinking**.

---

## ⭐ Featured Projects

### 🟢 End-to-End Automation Project (Wolt)

End-to-end UI automation project for the Wolt platform, focusing on real user flows and edge cases.

Key highlights:
- Built with Playwright, Python, and Pytest  
- Implements Page Object Model (POM) for scalability  
- Covers navigation flows, validations, and negative scenarios  
- Designed for stability and CI/CD execution  

🔗 Full Source Code: https://github.com/ygutmann/pom_project_wolt  

### 🟢 System-Level QA Project (TCP Client-Server)

A full system testing project involving communication between a Node.js server and a Unity client.

Key highlights:
- Implemented TCP-based communication with structured JSON messages  
- Designed and validated command-response flows (PING, GET_TIME, RANDOM_NUMBER)  
- Focus on system behavior, validation, and error handling  
- Includes logging and end-to-end interaction testing  

🔗 Full Source Code: https://github.com/ygutmann/anzu-home-assignment
